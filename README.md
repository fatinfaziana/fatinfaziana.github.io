# Fatin Faziana — Portfolio

**Live site:** https://fatinfaziana.github.io/

A one-page personal portfolio styled as a soft cream, blush and sage MacBook desktop.

## What's on the desktop
- **Folders (left):** About myself, Experience, Contributions, Beyond teaching, Projects. Hover a folder to peek at what's inside; click to open its information window.
- **Shah Alam map card:** shows the Shah Alam, Selangor base and links to Google Maps.
- **Music player:** a soft, original Ghibli-style background tune generated in the browser, with play/pause. It also plays and pauses from the dock icon.
- **About card:** a written introduction to Fatin Faziana.
- **Photo (right):** a cut-out portrait that blends into the desktop, with daisies falling on the back layer.
- **Dock:** quick links to About, Projects, Mail, Asterisk Academy, music, the Shah Alam map and GitHub.

## Sections
1. **About myself:** who I am, background, how to get in touch.
2. **Experience:** a horizontal year-by-year journey (2017, 2019, 2022, Today).
3. **Contributions:** results, how I teach, events and mentoring.
4. **Beyond teaching:** trading (with a not-financial-advice note) and vibe coding.
5. **Projects:** Learn Islam 101, mark4you, Trade 4 you, Asterisk Academy and GitHub.

## Built with
Plain HTML, CSS and JavaScript, with [Three.js](https://threejs.org/) (loaded from a CDN) for the 3D folders, photo and daisies. No build step.

## Files
- `index.html`: page shell and section content
- `assets/app.js`: 3D scene, windows, hover previews, music and sound
- `assets/style.css`: theme and layout
- `assets/me.png`: cut-out portrait
